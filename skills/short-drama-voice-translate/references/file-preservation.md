# 文件定位与原位写回

本脚本只处理UTF-8 TXT/MD和DOCX，不运行素材命令、不联网、不调用模型。程序输出写当前获准任务工作区，不写skill安装目录，不覆盖已有文件。原稿始终只读。

## 命令

将下面的SCRIPT替换为本skill目录下 scripts/voice_text_io.py 的绝对路径；使用已有Python，不需要第三方依赖。

```text
python -B SCRIPT inspect --source 原稿.docx --out 工作目录/source.json
python -B SCRIPT locate --source 原稿.docx --block word/document.xml:P000001 --text "别告诉他。"
python -B SCRIPT apply --source 原稿.docx --patch 工作目录/translations.json --out 工作目录/英文话音版.docx
python -B SCRIPT verify --source 原稿.docx --patch 工作目录/translations.json --output 工作目录/英文话音版.docx
```

inspect提供完整段落/行、定位、源文件SHA-256和读取限制。模型实际阅读全部相关原文，辨认哪些字符是话音；脚本不自动判别。locate只查选定块内原文的所有精确出现位置；同一句出现多次必须用上下文挑选，不只替换第一个。

译文清单示例（位置和哈希须用实际原稿，不照抄示例值）：

```json
{
  "version": 1,
  "source_sha256": "实际inspect返回的SHA-256",
  "translations": [
    {
      "block_id": "word/document.xml:P000001",
      "start": 8,
      "end": 13,
      "source": "别告诉他。",
      "target": "Don't tell him.",
      "channel": "dialogue"
    }
  ]
}
```

start/end是该块内Unicode字符的左闭右开位置，不是字节数。不可把姓名标签、时码、引号外动作或换行选入。先用locate取准确位置，再填译文；普通出现位置可能属于道具文字，必须由模型确认是实际话音。channel仅标身份，不会改变原文标签。可选speaker等工作备注不进入正文。

已有英文原句不要加入translations。中英混合话音可选择完整话音句作最小衔接，但不能夹带非话音。target须非空且不含中文汉字、换行或制表符；已有英文专名、数字和英语标点正常保留。真正要求英文中保留汉字的特殊译法不适用自动写回，单列请求用户决定，不能为通过检查擅自改名。

apply检查原稿指纹、原文片段、范围、重复/重叠、声音类别及目标格式，然后另存并回读。verify用未修改原稿和同一译文清单重建预期，检查目标文件；不能用旧输出伪装成原稿。未选中的文字、原时间码和镜头描述保持原样。程序验证仅针对明确选定的范围，不判断这是不是台词、不证明翻译质量或全剧覆盖；这三项由模型另核。

## DOCX保护边界

- 支持正文/表格、页眉页脚、脚注尾注和批注中的普通段落与w:t文字，逐块列出供上下文辨识；批注和页眉等不是默认翻译对象。文本框中能读取的普通段落也列出，不因其位置自动翻译。
- 只在确认为话音的w:t字符范围替换，不重建文档，不重写表格、样式、图片或关系文件；不提取附件执行。所有未修改ZIP成员的解压内容保持原字节，修改成员中未涉及的w:t及其他XML字节也保留。受影响w:t内的非话音文字保留，但XML实体的转义写法可能规范化，不将这种编码差异冒称为字节不变。
- 一个话音跨多个run时，译文放在该范围起始run，后续run仅移除该范围内原字，保留未选中的前后文。译文继承起始run样式；不承诺跨语言逐词映射原有加粗/颜色。必要时仅给受影响w:t添加xml:space以保存边界空格。
- 不自动替换跨段、跨制表/换行、域、修订或超链接等复杂边界的话音。inspect列读取限制，选中保护块时拒绝写回；先说明位置，索取可编辑的普通文本版本或另行明确处理范围，不静默抹掉格式。
- 嵌入图片里的字、公式、域结果、未读取的嵌入内容不能当作已翻译。ZIP内部数字签名存在时拒绝修改，以免假称签名仍有效。
- 保持文档结构不等于保持分页：英文变长可能换行或换页；没有页面渲染不能声称视觉排版实测通过。
- TXT/MD保持UTF-8 BOM、原换行和所有未选中字节。不把段落抽取结果当作完整原文重拼。

## 交付状态

返回完整的同格式新文件；如有未读/受保护部分或语义待核，说明实际完成范围。文件检查不代替翻译审读，不把“写回成功”说成“零穿帮、音频时长通过”。没有合适工具时可以交译文或完整文本并说明保留能力限制，不冒充已经原位修改DOCX。
