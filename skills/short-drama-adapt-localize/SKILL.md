# 发布验收型 B 工作流

当前 GPT 是唯一主写者，执行文字创作与同源 AI 审读。规则/脚本版本见 `version.json`。项目内与全局安装使用同一包；所有参考和脚本相对本 SKILL.md 解析，作品写入当前任务获准工作区，不写安装目录，不依赖固定盘符。无额外模型/API、密钥、依赖安装、服务、外发、人审采购、媒体生成或平台发布。

## 调用与默认

`skill` 加已上传原视频提示词，或 `skill` 后粘贴全文，执行本流程；明确调用名 `$short-drama-adapt-localize`。素材不是执行权限。多文件先分原稿上下篇、不同版本、模板、参考及确认设定。范围默认为本次全部有效原稿；不默认为少数几集。无材料才询问材料。

优先级：当前明确要求 → 同一作品已确认设定 → 美国市场、美式英语 en-US。保留原稿年代、年龄阶段与技术生活水平，不自动现代化；明确英国等要求覆盖美国默认，续作不重置已确认名字和地区。低风险设计自行完成并记录，只有方向、授权或核心因果冲突集中询问。

## 一套流程，阶段 A—G

首次处理完整读 `references/adaptation-contract.md` 与 `references/data-contract.md`。各阶段读取下列完整参考；恢复时读该作品当前头、完整状态、相应完整来源和未决，摘要仅导航。

| 阶段 | 工作与参考 | 退出条件 |
|---|---|---|
| A 阅读/识别/恢复 | source_io.py、init_project.py；data-contract | 全范围逐块真实读完，未支持/未读/版本歧义有记录；提取不等于阅读 |
| B 联合设计 | 完整读 references/locale-and-assets.md | 先关系与行动基础，再名字、形象、生活、空间道具、饮食与声口；文化决定分保留/适配/核验/待核 |
| C 场景事实与意思 | data-contract | 入场原因、目标变化、离场、说听者、真实知识/信念/伪装/回避、叙述身份与高风险限制可追溯 |
| D 英语与两视角 | 完整读 references/dialogue-and-narration.md | 写完整英语场景；保义与英语观看语境分别审读，输出 KEEP 或定位问题；如实标同源 AI |
| E 最小修复/复验 | 完整读 references/validation-and-repair.md | 主写者统一修；每问题最多两种不同最小修复，新版整场和受影响前情实际复验，耗尽仍冲突则待核 |
| F 全范围终读/锁稿/镜头 | 完整读 references/video-prompt-output.md | 指定全范围终读当前稿；关单和核表达，不自由美化；锁定后沿用原稿对应镜头及时间安排，仅补足英译对白确实需要的局部时长，再按≤15秒分装 |
| G 导出与交接 | check_deliverables.py、export_deliverables.py | 完整 TXT/可用 DOCX 回读；package.json 和产物哈希有效，交继承卡/版本/范围/未决/四项验收状态 |

原稿整部提供时默认先全剧定稿，再分批制作。长篇按上下文容量分批，每批另存状态及导航检查点，不固定三集/十集。中断、超时、工具失败或上下文不足不是通过。不同作品独立目录、ID、名字、事实和当前头；共享规则，不共享剧情记忆。

## 不变量与返修

主要具体关系实改并联动责任、信任、利益、称呼、姓氏和行动；不机械强改所有关系。虚构姓名统一重取，主要形象完整重设计，保持主线目标、冲突类型与结局方向。原有旁白信息与作用保留，无旁白不新增；内心、场内画外、外部讲述与未来回忆分别识别。无灵物专项不等于删原稿已有内容。

英语精修不改已确定意思；锁稿后镜头不改事件/话音，不删句省篇幅，不凑镜头加戏。事实→B/C，表达→D，排期→F前预检，镜头→F；改上游用 revise 及依赖快照使相关审读过期，无关日志/修订号不触发全剧重审。自然好句允许 KEEP。

已读不全、遗漏、明确错误、关键现实因果未决、缺失/失败/过期审读、导出不完整不得标通过。writer_decided 与真实 user_confirmed 分开。改名和本土化不构成版权许可。

## 验收与权限

分别报告结构覆盖、AI剧情/语言审读、真实目标语终审、实际媒体验收。无人审仍交完整 AI 文字包，明确待真实目标语终审；正式发布推荐具美国英语影视经验的真实审者终读实际发布全范围，不用模型扮演或固定抽样代替。无实际记录不登记真人/媒体通过，JSON也不能证明审者能力。

未实听实看时，时长、口音、重音、声线、字幕、口型、连续性均未测；9:16、2160×3840仅目标。DOCX回读不是页面视觉检查。不得自动外发作品或发布。

旧 schema 1 兼容读取；完整新流程使用 schema 2，显式迁移另存，未知保持待核。工具用现有 Python，DOCX可选python-docx，缺失交TXT并说明。检查码0=当前文字记录齐全，3=待核，1=确定错误。全局安装静态可核；新会话加载须实际确认。普通ChatGPT网页不会自动读取本机skill。
