# 锁稿后的镜头与成品

先锁事件/阶段、台词、关系、知识揭示、资产版本和时长，再镜头设计。镜头数量由叙事需求决定，不固定两镜/4秒/12秒，也不强求每段多镜。数量增加不能制造新动作、重复取钥匙、重复开门、暗示新的情绪动机。

每镜具备：时间区间、可见重点、景别、机位、构图/人物站位视线、具体运镜或固定、动作起止。每个事件的动作阶段按顺序只发生一次，多角度不是事件重演。状态保持镜可以没有新事件，但必须承接既有状态，不暗添危险或证据。

先设计连续表演，再包装≤15秒生成段；单段与镜头片段都≤15秒。长镜拆片写continuous_take_id及continues_shot_id，连续不等于新切镜。段内时间从0，但全局时间继续累加。

声音按已锁文字的字符区间映射，跨镜可以声音不断；跨段按连续时间和字符索引接续，不重复一句，不把说话人变旁白。显式记录计划停顿/同时发声，不自动把所有动作串行相加或全部重叠。英语字符预算不能替代试听。

段模板：
1. 集/段号、计划时长、新场次；只有有依据时给原片对应时码。
2. 基础设定：本段相关人物新形象、场景结构、道具动态状态、声音。
3. 氛围与画质：9:16、2160×3840目标、质感/共同环境/光影，每段一次。
4. 分镜：时间、景别、机位、构图、运镜、具体动作；声音独立时间轨，只播放一次。角色对白按角色写，原有旁白单列。
5. 必要结束状态供后段继承，不加黑屏、口号、悬念。

默认可独立复制每段，不用“同上”；只展开本段相关资产，不塞全剧资产库。镜头描述不重复转述台词内容，避免生成工具二次配音。无图可用文字设计，不能承诺真人脸/服装跨镜稳定性。

导出TXT和DOCX使用同一canonical_lines；回读同结构文字。继承卡记录名称映射、新关系、资产版本、最近结尾及待核。完整指定范围都输出，不以集标题数量假装内容齐全。
